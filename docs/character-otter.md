# 마스코트 수달 '달이'

- 모습: 사용자가 제공한 수달 캐릭터 시트(`video/concept/character/source/otter-sheet.webp`)를 쓴다. 시트의 표정 그림을 잘라 투명 배경 PNG로 만든 것이 `video/concept/character/otter-<표정>.png`다.
- **권리**: 이 이미지는 사용자가 직접 제공했고 저작권 문제가 없다고 확인해 주었다(2026-10-15 대화). 사용 권리에 대한 책임은 제공자에게 있고, 출처나 라이선스가 바뀌면 이 문서와 파일을 갱신한다. 외부 IP 캐릭터(예: 만화·애니·굿즈의 기존 캐릭터)로 확인되면 쓰지 않는다.
- 스프라이트 만들기: `python3 video/concept/character/make-sprites.py`(pillow, numpy 필요). 시트 해상도 한계로 2배 확대해 저장하므로 약간 부드럽다. 더 큰 해상도의 시트가 있으면 `source/`를 바꾸고 다시 실행한다.

## 표정 ↔ 영상의 mood
| mood | 스프라이트 | 쓰는 곳 |
|---|---|---|
| idle | 웃으며 볼에 손 | 기본 |
| think | 갸웃(?) | 궁금·질문 컷 |
| wow | 놀람 | 반전 컷(닿지 못함 등) |
| happy | 활짝 웃음 | 해결·성공 컷 |
| point | 손 흔들기 | 설명·CTA 컷 |
(`cry`, `angry`, `sleep`도 잘라 두었지만 템플릿 mood에는 아직 쓰지 않는다.)

## 움직임
- 그림은 컷의 mood에 맞춰 0.14초 동안 교차하며 바뀐다.
- 위아래로 가볍게 흔들리고, 말하는 동안 세로로 살짝 눌렸다 펴져 말하는 느낌을 낸다(입 모양을 따로 움직이지는 않는다).
- 말풍선은 컷마다 `react` 한 줄이다.

## 규칙
- 이 마스코트에 실존 인물, 상표 로고, 다른 캐릭터를 합성하지 않는다.
- 사실 설명(숫자·한계·출처)은 항상 화면 문구와 자막이 맡고, 마스코트는 반응과 흐름을 담당한다.
