# 숏폼 영상 규격 (재생속도 · TTS · 기승전결 · 기본 대본)

어떤 레포를 소개하든 **같은 스토리·같은 설정**으로 영상을 만든다. 특정 영상(레포)의 내용은 이 저장소에 두지 않는다. 내용은 `video/story/stories/<id>.json`(작업용, 템플릿은 `_template.json`)에만 쓰고, 이 문서는 틀을 정한다. 대본 작성 프롬프트는 `docs/script-prompt.md`.

## 1. 재생속도
| 항목 | 값 |
|---|---|
| 기준 길이(1.0배) | 44초 (5장면) |
| 최종 재생속도 | **1.2배** (영상·음성·자막 모두) → 약 36.7초 |
| 설정 위치 | `make-audio.py --speed 1.2` (기본값). 영상 `setpts`, 음성 `atempo`, `.srt` 시간이 같은 값으로 줄어든다 |
| 장면 전환 | 장면 끝 페이드아웃 0.12초, 요소 등장 최대 0.25초(이동 20px), 타이핑·줄 등장은 빠르게 |

## 2. TTS(나레이션)
| 항목 | 값 |
|---|---|
| 엔진 | gTTS 한국어 여성 음성(구글 번역 비공식). 수익화 채널은 약관을 확인하고 필요하면 상용 TTS로 교체 |
| 기본 말하기 속도 | 1.22배, 문장이 길면 최대 1.35배까지 자동 조절 |
| 시작 시점 | 각 장면 시작 +0.3초, 장면 길이 −0.6초 안에 끝내야 한다(넘으면 경고) |
| 배경음 | 사인파로 직접 합성한 잔잔한 코드 진행(저작권 없음), 음성 뒤에 −13dB, 전체 loudnorm −16 LUFS |
| 자막 | 음성 길이에 비례해 나눈 2줄 이내 자막을 영상에 새기고 `.srt`도 만든다. 하단 400px은 릴스 UI 영역이라 비운다 |
| 하지 않는 것 | 실존 인물·유명인 목소리 흉내(CLAUDE.md 5장 6항) |

## 3. 기승전결 스토리 (5장면, 고정)
| 장면 | 기승전결 | 시간(1.0배) | 화면 | 나레이션 예산 |
|---|---|---|---|---|
| 1 문제점 발생 | 기 | 0~6초 | 질문형 훅 + 문제 한두 줄 | 24음절 이하 |
| 2 왜 그럴까 | 승 | 6~14초 | 원인 3가지(번호 순서대로 등장) | 34음절 이하 |
| 3 깃 repo 추천 | 전 | 14~26초 | 레포 이름·소유자·한 줄 역할, 칩(라이선스·언어), 기능 3줄 | 50음절 이하 |
| 4 스타 갯수로 인지도 체크 | 전 | 26~34초 | ★ 개수 카운트업 + 기준일 + 한계 문구 | 32음절 이하 |
| 5 팔로우 후 댓글 | 결 | 34~44초 | 팔로우 → 댓글 → DM 3단계 + 키워드 배지 | 40음절 이하 |

장면 시간은 `video/story/index.html`의 `SC`와 `make-audio.py`의 `SCENES`가 같아야 한다. 문구는 모두 스토리 JSON에서 온다.

## 4. 기본 대본(뼈대) — `{{ }}`만 채운다
1. (문제) "{{누구나 겪는 문제를 질문형으로}}"
2. (왜 그럴까) "{{원인 한 가지를 쉬운 말로. 확인된 사실만}}"
3. (레포 추천) "이럴 땐 {{소유자}}의 오픈소스, {{레포 이름 한글 발음}}이에요. {{한 줄 역할}}. {{설치·사용 한 줄}}."
4. (스타) "스타는 {{반올림한 개수}}, {{한 줄 인지도}}. 다만 별이 많다고 품질이 보장되진 않아요."  ← 기준일은 화면에 표시
5. (결) "필요하신 분은 먼저 팔로우하고, 댓글에 두배라고 적어 주세요. DM으로 보내드려요."

규칙: 직접 확인한 사실만(확인 못 하면 "미확인"으로 빼기), 개인 경험·후기 지어내기 금지, 과장 금지, 제휴 링크가 있으면 수수료 안내를 첫 장면과 캡션 맨 위에. 댓글 키워드는 자막·캡션·`data/repos.json`이 모두 같아야 한다(기본 `두배`).

## 5. 만드는 순서
```bash
cp video/story/stories/_template.json video/story/stories/<레포>-ko.json   # 내용 채우기
node video/story/render.mjs video/story/stories/<레포>-ko.json out.mp4          # 무음 렌더(약 1분 30초)
python3 video/story/make-audio.py video/story/stories/<레포>-ko.json out.mp4 final.mp4   # 음성·배경음·자막·1.2배속
```
