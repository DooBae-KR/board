## ③ 인스타 캡션

왜 AI가 갑자기 내 파일과 서비스를 쓸 수 있게 됐을까요? 답의 한 조각이 MCP(Model Context Protocol)입니다. AI 앱을 외부 시스템에 연결하는 공개 표준이고, 앱(호스트)이 서버마다 클라이언트를 만들어 서버의 도구·자원·프롬프트를 씁니다.

예시 레포: chrisryugj/korean-law-mcp (MIT, ★약 3천, 2026-10-15 기준)

팔로우 후 댓글에 `MCP` 남기면 DM으로 링크를 보내드려요.

한계: MCP 서버마다 별도 설치·설정이 필요하고, 이 예시 서버는 법제처 Open API 키(무료 발급)가 필요합니다. 개인 개발자 도구이며 법률 자문이 아닙니다.

## ⑤ 자체 점검

미확인 항목
- korean-law-mcp ★ 정확한 수치: 페이지가 "2.7k"로만 표시되어 "약 3천"으로 반올림. 정확 수치는 미확인.
- README에 "비공식"이라는 명시 문구는 없음(미확인). 확인된 사실은 개인 개발자 작성(류주임 @ 광진구청 AI동호회)과 "법적 효력이 필요한 판단은 원문 확인" 안내이며, 대본·캡션은 "개인 개발자 도구, 법률 자문 아님"으로만 표현했다.
- 컷 3a·3b의 "연결 통로 없이는 AI 혼자 닿지 못한다"는 설명용 해석이다. 공식 문서는 "MCP가 AI 앱과 외부 시스템을 연결해 접근과 작업을 가능하게 한다"까지만 말한다. 영상에서 단정하지 말고 질문 톤을 유지한다.
- 파일시스템 서버가 어떤 도구를 가졌는지: 미확인(문서에 목록 없음), 그래서 예시는 공식 문서의 `weather_current` 예시를 쓰고 "문서 예시"로 표기했다.
