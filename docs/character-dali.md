# 캐릭터 시트: 달이 (수달 마스코트)

원본: `video/concept/character/dali.svg` (viewBox 0 0 240 290). 영상 템플릿 `video/concept/index.html`이 id로 표정·팔·꼬리를 움직인다.

## 성격
호기심 많고 말이 많은 개념 설명 담당. 새 개념이 나오면 먼저 놀라고, 이해하면 크게 웃는다.

## 비례
- 머리가 전체 높이의 약 63%(가로 212, 세로 184 타원). 몸은 작고 통통, 팔다리는 짧다.
- 작은 둥근 귀, 멀리 떨어진 큰 눈(지름 22), 아주 작은 코와 입, 납작하고 둥근 수달 꼬리.
- 외곽선은 검정이 아닌 진한 갈색 5px.

## 소품 (오리지널 요소)
- 머리 위 오른쪽 조개껍데기 머리핀(`shell`), 가슴의 물방울 펜던트. 둘 다 `bitroot` 안이라 몸 흔들림을 따라간다.

## 표정 5가지 (템플릿 MOODS 값)
- idle: 팔을 살짝 내리고 눈썹 수평, 작은 입. 기본.
- think: 오른팔을 들어 볼에 대고 눈썹을 비스듬히, 입은 작게.
- wow: 두 팔을 얼굴 옆으로 올리고 눈이 커지며 입이 크게 열린다.
- happy: 팔을 들고 눈썹을 올리며 입이 넓게 웃는다.
- point: 오른팔을 위로 뻗어 가리킨다.

## 오리지널 설계 메모
참고로 삼은 것은 '아주 큰 둥근 머리, 작은 몸, 위는 회갈색·아래는 크림인 얼굴, 분홍 볼 줄무늬, 단순한 이목구비' 같은 일반적 특징뿐이다. 특정 캐릭터의 윤곽·배치를 옮기지 않았고, 조개핀·물방울 목걸이, 둥근 팔, 얼굴 경계를 완만한 물결선으로 한 점, 납작한 꼬리 모양으로 차별화했다. 모든 도형은 타원·원·단순 곡선으로 직접 구성했다.

## 사용 규칙
- 기존 캐릭터·IP·실존 인물·로고와 합성하거나 닮게 바꾸지 않는다.
- 필수 id(`bitroot`, `tail`, `armL`, `armR`, `eL`, `eR`, `pL`, `pR`, `bL`, `bR`, `mouth`)를 지운다·바꾸지 않는다.
- 외곽선을 검정으로 바꾸거나 소품을 몸 그룹 밖으로 빼지 않는다.
